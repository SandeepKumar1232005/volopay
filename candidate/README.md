Revenue Intelligence Inbox

Overview

Revenue Intelligence Inbox is a workspace designed to help sales managers review incoming sales conversations, identify important information, organize records, and make routing decisions.

Live application: https://volopay-one.vercel.app/

Features

- Review sales call and meeting records.
- Organize conversations using categories and routing rules.
- Identify important findings and supporting evidence.
- Review conversation summaries, decisions, and exceptions.
- Export processed data in CSV and JSON formats, where supported by the application.

Setup Instructions

1. Clone or download the source-code repository.
2. Open the project folder in Visual Studio Code.
3. Locate the application's entry point.
4. If the application is a static HTML project, open `index.html` in a browser or use the VS Code Live Server extension.
5. If the project uses a framework or build tool, install the required dependencies and run the development command specified in `package.json`.

Usage Instructions

1. Open the deployed application.
2. Review the available conversation records.
3. Examine the source evidence before making a classification or routing decision.
4. Apply the appropriate categories and routing rules.
5. Review the results and verify important decisions.
6. Export the available results as CSV and the JSON manifest, if implemented.
